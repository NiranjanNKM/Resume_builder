# RoleFit — Resume Builder

RoleFit is a privacy-first resume tailoring application hosted using GitHub Pages.

It helps users tailor their resume based on a job description by identifying relevant skills, keywords, and potential gaps.

## Live Application

[Open RoleFit Resume Builder](https://niranjannkm.github.io/Resume_builder/)

## Features

- Create and edit a baseline resume
- Paste a complete job description
- Add a LinkedIn or public job link
- Identify relevant job-description keywords
- Calculate a resume match signal
- Highlight possible skill gaps
- Generate a tailored resume
- Download the tailored resume as a text file
- Print or save the resume as PDF
- Store resume information locally in the browser
- No external server or database required
- Responsive desktop and mobile design

## Privacy

RoleFit runs entirely inside the browser.

Resume information is stored using browser local storage and is not uploaded to a server.

## LinkedIn Job Links

LinkedIn normally blocks websites from automatically reading job descriptions.

If automatic access is unavailable:

1. Open the LinkedIn job posting.
2. Copy the complete job description.
3. Paste it into RoleFit.
4. Click **Tailor my resume**.
